## 本次重磅更新点

### 1. SVG 矢量虚线 100% 死死钉在【节点正右端顶点 `(x + nodeSize/2, y)`】
- **SVG 矢量绘制**：彻底消除了由于 CSS 容器导致的纵向偏移，采用 SVG 矢量画布绘制！
- **正右顶点**：起点坐标强制绑定为 **`X = activeNodeX + nodeSize/2`**，**`Y = activeNodeY`**！起点与节点的中心水平线绝对 100% 绝对一致，**横向直直拉伸连接至悬浮窗左壁，0 像素偏移！**

### 2. 内套圆环升级为“极亮白色发光霓虹灯”强效呼吸灯
- **极亮高光**：内套圆环彻底升级为 **发光亮白霓虹发光环 (`border-white bg-amber-400/20 animate-pulse shadow-[0_0_10px_#ffffff,0_0_18px_#f59e0b]`)**！在橙色/深色节点背景上呈现出极具震撼力的亮暗辉光强效呼吸脉冲！

### 3. 点击助手外任何屏幕空白处，瞬间收起软件
- **空白一键隐退**：全屏底层 Overlay 开启背景点击事件！唤起助手后，您**点击圆盘与悬浮窗外任何地方的屏幕空白处，瞬间自动收起并隐藏软件**！

### 4. 快捷启动软件时，全屏与悬浮窗全量自动关掉
- **自动隐退**：当在快捷启动列表中点击【启动/运行】软件或网页时，助手会在启动软件的同时，**全量自动隐藏全屏助手与悬浮窗**，绝不残留挡住已打开的程序！

### 5. 应用启动“🚀 飞天火箭 Toast 炫酷反馈动画”
- **极致视效反馈**：点击启动按键瞬间，屏幕顶部会弹出一道 **“🚀 正在启动 [应用名]...”** 的精致动效 Toast，让您对程序是否成功启动拥有 100% 的极佳视效心理反馈！
