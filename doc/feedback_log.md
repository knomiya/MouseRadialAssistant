## [2026-07-21 第二十一轮] 选文件防收起深度拦截、应用禁用白名单、正右切点SVG精准对齐与底部Toast

### 问题 1：选文件点击【打开】后文件框和助手全退隐收起致命 Bug
* **用户描述**：我再配置应用启动的时候，点击打开之后这个文件框和这个助手软件都没了，需要我再呼出才能点保存，我点击打开之后，可以只关这个文件框吗？
* **致命原因诊断**：
  `rfd::FileDialog` 点击【打开】关闭瞬间，Windows 将前台焦点切回桌面，触发 Tauri 窗口 `Focused(false)` 失焦事件。因 `select_exe_file` 在对话框返回瞬间就解锁了 `is_dialog_open = false`，导致失焦事件拦截失效，触发了 `window.hide()`！
* **彻底修复方案**：
  在 `select_exe_file` 对话框返回后，保持 `is_dialog_open = true` 延迟 500ms 后才解锁，并在 Rust 端重新强行调用 `window.show()` 和 `window.set_focus()`！失焦保护百分百生效，只关闭文件框，助手稳定留在前台供用户点击【保存】！

### 问题 2：虚线偏上，未精准连接圆的绝对正右顶点 (`nodeRightApexX, nodeCenterY`)
* **用户描述**：线还是不对，这是按钮圆的右顶点吗？
* **致命原因诊断**：
  之前 SVG 容器使用了包含 `width/height` 的定位，导致 `(0,0)` 坐标系发生了二次偏移。
* **彻底修复方案**：
  SVG 画布设为 `width: 0, height: 0, overflow: 'visible'`，使其 `(0,0)` 物理原点与唤醒中心 `X` 点 100% 绝对重合！
  直接画 `<line x1={activeNodeX + nodeSize / 2} y1={activeNodeY} x2={cardLeftX} y2={activeNodeY} />`！
  **Y 坐标严格相等于 `activeNodeY`**，线条从节点正右侧中点水平延伸至悬浮窗左壁，0 像素偏移！

### 问题 3：Tab 名称替换为“软件设置” & 新增“禁用应用白名单” (游戏防误触)
* **用户描述**：热键唤醒这个换成软件设置，然后再这个开机启动前面加一个配置，应用白名单，可以设置再配置的软件运行时，按设置的热键也不会把这个软件呼出。
* **修复方案**：
  1. Tab 1 重命名为 **“软件设置”**。
  2. 在设置中新增 **“全局禁用白名单 (进程/窗口关键字)”** 配置项。
  3. Win32 后端在按下热键时，实时检测前台窗口进程名（`GetForegroundWindow`），若匹配白名单，则忽略唤醒，游戏场景绝对防误触！

### 问题 4：启动 Toast 移动至屏幕底部
* **用户描述**：这个通知可以往下放，放在我画框这里吗？
* **修复方案**：
  Toast 提示位置从顶部移动至屏幕底部 `bottom-12 left-1/2 -translate-x-1/2`，视觉清爽优雅。
